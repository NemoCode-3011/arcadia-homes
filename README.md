# Arcadia Homes

Arcadia Homes is a real-estate web application concept for browsing property listings and providing separate experiences for visitors, agents, and administrators.

> **Project status:** Frontend application. Deployment and the status of any production backend have not been verified.

## What it includes

- Public landing, about, and contact pages
- Property listing and property detail routes
- Sign-in and sign-up pages
- Separate admin-facing areas for properties, agents, messages, and settings
- Route protection for restricted areas
- Shared authentication and property state contexts
- Dashboard layouts and reusable UI components

## Tech stack

- React 19 and TypeScript
- Vite
- React Router
- Tailwind CSS 4
- Axios
- Recharts
- React Hot Toast

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Useful scripts:

```bash
npm run build
npm run lint
npm run preview
```

## Project notes

This repository documents the frontend implementation. Do not assume that every route is connected to a production API or that authentication and property data are production-ready without verifying the relevant integration and environment.

A live demo, screenshots, and additional setup details can be added once the deployed state and any backend requirements are confirmed.
